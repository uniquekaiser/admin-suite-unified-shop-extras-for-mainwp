# Admin Suite and Unified Shop Extras for MainWP

One MainWP add-on for administering Admin Suite and Unified Shop Extras across connected WordPress sites.

Requires WordPress 6.9, PHP 8.2, and MainWP Dashboard 6.5 or later. Tested with WordPress 7.1.3 and MainWP Dashboard and Child 6.5.
