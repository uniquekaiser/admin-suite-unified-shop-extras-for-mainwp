# Admin Suite and Unified Shop Extras for MainWP

This context covers administering Admin Suite and Unified Shop Extras from a MainWP Dashboard.

## Language

**Dashboard add-on**:
The single MainWP extension that brings both **Products** into the dashboard.
_Avoid_: Child add-on, integration plugin

**Product**:
Either Admin Suite or Unified Shop Extras, as managed by the **Dashboard add-on**.

**Edition**:
The Lite or Pro form of a **Product**.

**Plugin basename**:
The WordPress identity of an installed **Edition**, made up of its plugin directory and main file.

**Product package**:
The publisher-approved installable ZIP for a specific **Product**, **Edition**, and version.

**Pro package source**:
The active, licensed Pro **Edition** on the MainWP Dashboard from which a Pro **Product package** is obtained.

**Release manifest**:
The publisher's record of the files in an approved **Product package** for one version of an **Edition**.

**Publisher catalog**:
A signed record of approved **Product packages** and **Release manifests** for both products.

**Managed site**:
A WordPress site connected to the MainWP Dashboard through MainWP Child.
_Avoid_: Target when referring to a site outside an operation

**Plugin activation**:
Making an installed **Product** active in WordPress on a **Managed site**.

**License activation**:
Associating a license with a specific **Product** on a specific **Managed site**.

**One-time license**:
A license supplied for one **License activation**.

**Saved license**:
A license retained for reuse on **Managed sites** for one **Product**.

**Default license**:
The **Saved license** available across **Managed sites** for one **Product**.

**Site license override**:
A **Saved license** assigned to one **Managed site** for one **Product**.

**Configuration profile**:
A selection of settings for one **Product**, captured from a reference **Managed site** for application to another site.

**Profile preview**:
The proposed setting changes and compatibility results for applying a **Configuration profile** to a specific **Managed site**.

**Last verified status**:
The most recent confirmed **Product** status for a **Managed site**, with the time it was checked.

**Operation history**:
The record of an operator's actions and their outcomes for a **Product** on a **Managed site**.
